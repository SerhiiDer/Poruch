# Як почати працювати над «Поруч»

Інструкція для учасників, які не програмують. Код ви писатимете разом з Claude — просто описуєте словами, що хочете змінити, а Claude робить решту.

Не бійтеся щось зламати: кожна ваша зміна живе в окремій «гілці» (копії проєкту), і Serg переглядає її, перш ніж вона потрапить в основний застосунок.

---

## 1. Акаунти

1. **GitHub** — зареєструйтесь на [github.com](https://github.com) і надішліть Serg свій логін.
2. Serg надішле запрошення — **прийміть його** в листі від GitHub або на [github.com/notifications](https://github.com/notifications).
3. **Claude** — потрібна підписка Pro або вище на [claude.ai](https://claude.ai).

## 2. Програми

На компʼютер (усе безкоштовне, при встановленні скрізь можна тиснути «Next»):

1. **Claude** — застосунок для компʼютера: [claude.ai/download](https://claude.ai/download). Увійдіть своїм акаунтом.
2. **Git** — [git-scm.com/downloads](https://git-scm.com/downloads). Claude через нього зберігає ваші зміни.
3. **Node.js**, версія LTS — [nodejs.org](https://nodejs.org). Claude через нього запускає застосунок.

На телефон — **Expo Go** (App Store або Google Play). У ньому ви бачитимете застосунок.

## 3. Завантажити проєкт (один раз)

1. Створіть на компʼютері порожню папку, наприклад `Документи\Projects`.
2. У застосунку Claude відкрийте вкладку **Code** і виберіть цю папку.
3. Напишіть Claude:

   > Завантаж проєкт https://github.com/SerhiiDer/Poruch.git у цю папку і підготуй його до запуску: встанови залежності в apps/mobile і скопіюй .env.example у .env.

   Якщо відкриється вікно входу в GitHub — увійдіть, це нормально.
4. Коли Claude закінчить, відкрийте у вкладці **Code** вже папку `Projects\Poruch`. Надалі завжди працюйте з неї — тоді Claude бачить правила проєкту.

## 4. Подивитися застосунок на телефоні

Напишіть Claude:

> Запусти застосунок і скажи, як відкрити його на телефоні в Expo Go.

Claude запустить його і дасть адресу на кшталт `exp://192.168.1.20:8081`. У Expo Go натисніть **«Enter URL manually»**, введіть її — і застосунок відкриється.

- Телефон і компʼютер мають бути в **одній Wi-Fi мережі**.
- Не підключається — скажіть Claude: «не підключається, запусти через tunnel».
- Поки застосунок запущений, кожна зміна одразу видно на телефоні.

## 5. Як працювати

1. Перед кожною новою задачею напишіть: **«Почнімо нову задачу»** — Claude оновить проєкт і створить для вас окрему гілку.
2. Опишіть, що хочете, звичайними словами, наприклад:
   *«Хочу на сторінці івенту кнопку "Додати в календар"»*.
3. Подивіться результат на телефоні. Не подобається — скажіть, що змінити.
4. Коли все добре, напишіть: **«Відправ це Serg на перевірку»**.
   Claude збереже зміни й створить Pull Request — запит для Serg.
5. Serg перегляне й додасть у застосунок.

## 6. Чого не робити

- Не просіть Claude змінювати **базу даних** (таблиці, заклади, івенти) — це робить Serg. Якщо для ідеї потрібні нові дані, просто опишіть це, Claude запише для Serg.
- Не вставляйте в чат паролі чи «секретні» ключі.
- Якщо Claude питає дозволу на щось незрозуміле — спитайте його «навіщо це?» або напишіть Serg.

## 7. Якщо щось пішло не так

- **Застосунок показує червону помилку** — зробіть скріншот, вставте його в чат і напишіть: «ось помилка, виправ».
- **Хочу повернути, як було** — скажіть Claude: «відкоти мої зміни в цій гілці».
- **Нічого не зрозуміло** — пишіть Serg. Зламати основний застосунок ви не можете: усе проходить через його перевірку.
